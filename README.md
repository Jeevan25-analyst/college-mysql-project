
# College Database Management System – MySQL
MySQL College Database Management System project

## Project Overview

This project is a College Database Management System developed using MySQL.
The database manages student information, course information, and student enrollments.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench
- 
## Database Tables

### 1. Students
Stores student information such as:

- Student ID
- Student Name
- Email
- Phone
- City

### 2. Courses
Stores course information such as:

- Course ID
- Course Name
- Duration
- Course Fee

### 3. Enrollments
Stores student course enrollment information such as:

- Enrollment ID
- Student ID
- Course ID
- Enrollment Date
- Status
- Fee Paid

## Sample Analysis Questions
The project answers questions such as:

1. How many students are enrolled in each course?
2. Which course has the highest number of students?
3. Which students are currently active?
4. Which courses have the highest enrollment?
